# Telegram Quiz Bot

Telegram Quiz Bot — це інтерактивний Telegram-бот, розроблений мовою Ruby для перевірки знань користувачів у сфері інформаційних технологій.

Бот пропонує запитання з чотирма варіантами відповідей, перевіряє правильність вибору та підраховує підсумковий результат.

## Функціональні можливості

- Проведення інтерактивних вікторин.
- Випадковий порядок запитань.
- Перевірка правильності відповідей.
- Автоматичний підрахунок балів.
- Перегляд результатів останньої вікторини.
- Керування за допомогою кнопок Telegram.

## Використані технології

- **Ruby** — мова програмування.
- **telegram-bot-ruby** — бібліотека для роботи з Telegram Bot API.
- **JSON** — зберігання запитань.
- **Hash** — тимчасове зберігання результатів користувачів.

## Встановлення

1. Клонувати репозиторій:

```bash
git clone https://github.com/USERNAME/TelegramQuiz.git
cd TelegramQuiz
```

2. Встановити необхідні бібліотеки:

```bash
bundle install
```

3. Створити Telegram-бота через [@BotFather](https://t.me/BotFather) та отримати токен.

4. Вказати токен у змінній середовища (PowerShell):

```powershell
$env:TELEGRAM_BOT_TOKEN = "YOUR_TOKEN"
```

5. Запустити бота:

```bash
bundle exec ruby bot.rb
```

## Команди бота

| Команда | Опис |
|---|---|
| `/start` | Запуск бота та головне меню |
| `/quiz` | Початок нової вікторини |
| `/stats` | Перегляд останнього результату |
| `/help` | Довідка про команди |

## Зберігання даних

Запитання зберігаються у файлі `questions.json`. Інформація про поточну вікторину та результати користувачів тимчасово зберігається у Hash. Після перезапуску програми статистика скидається.
